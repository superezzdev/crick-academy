# Chandigarh Cricket Academy - PWA & Web App Icons

This folder contains the icon assets for the Chandigarh Cricket Academy Progressive Web App (PWA), favicon, and iOS Home Screen icons.

## Where to Replace Real Production Icons

To replace these placeholders with your official academy branding / logos, drop your replacement files directly into this folder (`apps/web/public/icons/`) using the following filenames and specifications:

| File Name | Dimensions | Format | Purpose / Usage |
| :--- | :--- | :--- | :--- |
| `icon-192.png` | **192 x 192 px** | PNG (24-bit with alpha) | Standard Android / Chrome PWA install icon |
| `icon-192-maskable.png` | **192 x 192 px** | PNG (solid background) | Android adaptive / maskable icon (safe zone padded) |
| `icon-512.png` | **512 x 512 px** | PNG (24-bit with alpha) | High-res splash screen & PWA install icon |
| `icon-512-maskable.png` | **512 x 512 px** | PNG (solid background) | High-res adaptive / maskable icon (safe zone padded) |
| `apple-touch-icon.png` | **180 x 180 px** | PNG (no transparency) | iOS Safari "Add to Home Screen" bookmark icon |
| `favicon.png` | **32 x 32 px** | PNG | Browser tab favicon |
| `icon-192.svg` | Vector | SVG | Scalable vector icon |
| `icon-512.svg` | Vector | SVG | Scalable vector icon |

## Design Guidelines
- **Primary Brand Color (Theme Color):** `#0B3D2E` (Deep Academy Emerald Green)
- **Secondary Brand Color (Background):** `#F5F1E6` (Warm Cricket Cream)
- **Accent Colors:** `#E8C468` (Gold Stumps) & `#C1121F` (Leather Ball Red)
- **Maskable Icons:** Ensure the important logo artwork fits inside the center 80% safe zone circle (minimum 10% padding on all sides) with a solid background color (`#0B3D2E`).
